### Привет! Я En0t (`bad-cyber`) 👋

Разрабатываю инструменты для безопасности в вебе, кроссбраузерные расширения и **AI-решения** (RAG-пайплайны, семантический поиск, интеллектуальные Telegram-боты).

#### 🛡️ Главные проекты
- **[Astra — Древо Щит](https://github.com/bad-cyber/astra-tree-shield)** — бесплатное открытое кроссбраузерное расширение (Manifest V3) для защиты от фишинга, скрытых криптомайнеров, кликджекинга и рекламных трекеров.
- **[Semantic Movie Bot](https://github.com/bad-cyber/semantic-movie-bot)** — AI-киносоветчик в Telegram с семантическим поиском по смыслу и атмосфере (Qdrant, Bi-Encoder + Cross-Encoder реранкинг, LLM-объяснения, защита от Prompt Injection).
- **[CodeToMovieBot](https://github.com/bad-cyber/CodeToMovieBot)** — Telegram-бот на Python для управления коллекцией фильмов с рейтингованием и поиском информации.
