### Привет! Я En0t (`bad-cyber`) 👋

Разрабатываю инструменты для безопасности в вебе, браузерные расширения и Telegram-ботов.

#### 🛡️ Главные проекты
- **[Astra — Древо Щит](https://github.com/bad-cyber/astra-tree-shield)** — бесплатное расширение для Chrome и Opera (Manifest V3) для защиты от фишинга, скрытых криптомайнеров, кликджекинга и рекламных трекеров.
- **[CodeToMovieBot](https://github.com/bad-cyber/CodeToMovieBot)** — Telegram-бот на Python для управления коллекцией фильмов с рейтингованием и поиском информации.
